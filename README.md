# Cyber Security Internship – Task 1

## Project Title
**Scan Your Local Network for Open Ports Using Nmap**

## 1. Introduction
Port scanning is a process used to identify open ports on devices in a network. It helps understand network services and identify potential security risks.

Nmap is a free network scanning tool used to discover open ports and services.

## 2. Objective
- To understand network port scanning.
- To learn how to use Nmap.
- To identify open ports.
- To understand common network services.
- To identify potential security risks.

## 3. Tools Used
- Nmap – Network scanning tool.
- Command Prompt – To execute Nmap commands.
- Windows OS – Operating system.
- Wireshark – Optional packet analysis tool.

## 4. Procedure
1. Downloaded and installed Nmap.
2. Checked the local IP configuration.
3. Performed a scan on an authorized device.
4. Recorded the scan results.
5. Studied the services associated with detected ports.
6. Identified potential security risks.

## 5. Nmap Command Used
```bash
nmap 127.0.0.1
```

## 6. Project Folder Structure
- 01_Installation – Nmap installation screenshot.
- 02_Scan_Results – Actual Nmap scan output.
- 03_Screenshots – Practical work screenshots.
- 04_Report – Final assignment report.

## 7. Learning Outcomes
- Understanding open ports.
- Learning basic Nmap commands.
- Understanding network services.
- Identifying potential network security risks.
- Learning basic network security concepts.

## 8. Conclusion
This task helped me understand the basics of network port scanning using Nmap. I learned how to identify port states, understand network services, and recognize potential security risks.
